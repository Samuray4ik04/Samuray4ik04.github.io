# samuray4ik04.github.io

Личная страница Samuray43k: https://samuray4ik04.github.io/
Статический HTML, CSS и JavaScript, без сборки и зависимостей для сайта.

## Оформление

Две героини, одна палитра: сливочный и медовый Махиру Шиины плюс мята,
шалфей и глубокий зелёный Хохо. Иллюстрации стоят на двух наклонённых
карточках. Крупная антиква сочетается с небольшими моноширинными подписями.

Переключатель «Вместе / Mahiru / Huohuo» меняет настроение всей страницы:
светлое смешанное, тёплое медовое и тёмное зелёное. Выбор сохраняется
в localStorage; при недоступном хранилище переключение продолжает работать.
Google Fonts: Cormorant Garamond, Manrope, JetBrains Mono; есть системные замены.

Персонажи живые: карточки наклоняются за курсором, а на телефоне — за наклоном
устройства (на iOS разрешение спрашивается по первому тапу). По клику на
Махиру или Хохо появляется их реплика в облачке.

Бенто «Сейчас» показывает, чем я живу: код, аниме, игры и музыку.
Время последнего пуша подтягивается из GitHub API и кэшируется на 10 минут;
без сети остаётся статичный текст. Поверх страницы лежит лёгкое бумажное
зерно, а блоки мягко проявляются при скролле (CSS scroll-driven animations;
в браузерах без поддержки они просто видны сразу).

Ссылки на Telegram, GitHub и TikTok сохранены. Кнопка со стрелкой листает
пять записок про любовь. Без JavaScript видны все записки и все ссылки,
а неработающие элементы управления скрыты. Учтён prefers-reduced-motion,
есть клавиатурный фокус, ссылка пропуска навигации и aria-live для записок.

## Файлы

- `index.html` — содержание страницы и метаданные.
- `assets/style.css` — общие стили, три палитры, адаптивная вёрстка и страница 404.
- `assets/site.js` — выбор настроения и переключение записок.
- `assets/characters.js` — наклон карточек и реплики персонажей.
- `assets/now.css` — бенто «Сейчас», зерно и появление при скролле.
- `assets/now.js` — последний пуш из GitHub API.
- `assets/mahiru.png`, `assets/huohuo.webp` — локальные иллюстрации.
- `404.html` — страница ошибки с переходом домой.
- `tools/og-card.html` — макет превью ссылки 1200×630.
- `tools/build-assets.sh` — пересборка `og-cover.jpg` через Chromium и ImageMagick.
- Иконки и исходный аватар сохранены в корне.

## Источники образов и иллюстраций

Цвета — дизайнерская интерпретация образов, а не официальные цветовые коды.

- Махиру Шиина, «The Angel Next Door Spoils Me Rotten»:
  [официальный сайт аниме](https://otonarino-tenshisama.jp/),
  [иллюстрация персонажа](https://otonarino-tenshisama.jp/wordpress/wp-content/themes/otonari/images/characterS2-2.png).
- Хохо, Honkai: Star Rail:
  [официальное представление персонажа на HoYoLAB](https://www.hoyolab.com/article/22882695),
  [страница HoYoWiki](https://wiki.hoyolab.com/pc/hsr/entry/1533),
  [копия иллюстрации на Icy Veins](https://static.icy-veins.com/images/honkai-star-rail/characters/full/huohuo.webp).

Персонажи и иллюстрации принадлежат соответствующим правообладателям;
это личная неофициальная страница. Картинки размещены локально, без хотлинков.

## Запуск

```sh
python3 -m http.server 8000
```

Открыть http://localhost:8000. GitHub Pages публикует ветку `master`.

Пересобрать превью (нужны Chromium и ImageMagick):

```sh
sh tools/build-assets.sh
# или
sh tools/build-assets.sh /path/to/chrome
```
