# samuray4ik04.github.io

Личная страница-визитка. Один HTML-файл, без сборки и зависимостей.

**→ https://samuray4ik04.github.io/**

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | вся страница: разметка, стили и скрипт в одном файле |
| `404.html` | «такой сцены нет» в том же оформлении |
| `ava-600.webp` / `.jpg` | аватар, 600×600 (webp с jpg-фолбэком) |
| `og-cover.jpg` | карточка превью 1200×630 для Telegram, X и прочих |
| `favicon.png`, `apple-touch-icon.png` | иконки, 64×64 и 180×180 |
| `tools/og-card.html` | исходник карточки превью |
| `tools/build-assets.sh` | пересборка `og-cover.jpg` |

## Оформление

Страница собрана как сцена визуальной новеллы: слева спрайт, справа диалоговое
окно, а ссылки — это варианты ответа.

- **краски** — сняты с аватарки: бумага `#EEF3F0`, чернила `#101B17`,
  мята `#7FDCBB`, хвоя `#23443A`, лёд `#1B6E9F`, сирень `#B7BFFA` с бликов на глазах;
- **шрифты** — [Prata](https://fonts.google.com/specimen/Prata) для имени,
  [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) курсивом
  для реплик — у них свой голос, отдельный от имени,
  [Manrope](https://fonts.google.com/specimen/Manrope) для основного текста,
  [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) для меток;
- **стекло** — окно, кнопка и варианты ответа сделаны из одного материала:
  полупрозрачная заливка, `backdrop-filter` с блюром и подсветкой насыщенности,
  блик по верхней кромке. Под ними медленно дышат три пятна света — иначе стеклу
  нечего преломлять. Где `backdrop-filter` не поддерживается, окно становится плотным;
- спрайт лежит на мятной подложке через `mix-blend-mode: multiply` — белый фон
  картинки растворяется, персонаж остаётся;
- тёмная тема через `prefers-color-scheme`;
- все текстовые пары проходят WCAG AA (≥ 4.5:1);
- анимации отключаются при `prefers-reduced-motion`, реплика тогда появляется целиком.

### Реплики

Кнопка «Дальше» листает пять реплик про любовь — они печатаются по букве,
как в новелле, и счётчик показывает, где ты находишься.

Реплики лежат в разметке обычным списком `<ol class="lines">`. Скрипт забирает
их оттуда и заменяет список на печатающуюся строку, поэтому без JavaScript
видно все реплики сразу. Чтобы добавить новую, допиши `<li>` — трогать скрипт не нужно.

## Разработка

Сборка не нужна — достаточно открыть файл или поднять любой статический сервер:

```sh
python3 -m http.server 8000
```

Деплой: пуш в `master`, дальше GitHub Pages сам.

## Пересобрать карточку превью

`og-cover.jpg` рисуется тем же браузером и теми же шрифтами, что и страница,
из `tools/og-card.html` — поэтому превью не разъезжается с дизайном.
Нужны chromium и ImageMagick:

```sh
sh tools/build-assets.sh
```

Если браузер называется иначе, передай его первым аргументом:
`sh tools/build-assets.sh google-chrome`.
