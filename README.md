# samuray4ik04.github.io

Личная страница-визитка в виде самиздатовского зина. Один HTML-файл, без сборки и зависимостей.

**→ https://samuray4ik04.github.io/**

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | вся страница: разметка, стили и скрипт в одном файле |
| `404.html` | «лист не отпечатался» в том же оформлении |
| `ava-600.webp` / `.jpg` | аватар, 600×600 (webp с jpg-фолбэком) |
| `og-cover.jpg` | карточка превью 1200×630 для Telegram, X и прочих |
| `favicon.png`, `apple-touch-icon.png` | иконки, 64×64 и 180×180 |

## Оформление

Ксерокс-зин: газетная бумага, две краски и одна из них не попала.

- **цвета** — газета `#DCD8CB`, чёрная краска `#14110E`, красная `#E8443A`, красный текст `#A81219`;
- **шрифты** — [Oswald](https://fonts.google.com/specimen/Oswald) для заголовков, [PT Mono](https://fonts.google.com/specimen/PT+Mono) для текста, [Caveat](https://fonts.google.com/specimen/Caveat) для пометок маркером;
- тёмная тема через `prefers-color-scheme` — ночная смена, печать белым по чёрному;
- все текстовые пары проходят WCAG AA (≥ 4.5:1), красный работает как заливка и как текст в двух разных тонах;
- анимации отключаются при `prefers-reduced-motion`.

### Ксерокс

Кнопка «Прогнать через ксерокс» снимает копию с копии: красная краска уезжает от чёрной,
контраст пережимается, тонер мылит, плашки дрожат, лист ложится косо. Семь поколений,
дальше — «Взять чистый оригинал».

Всё держится на одной CSS-переменной `--gen`: от неё считаются непопадание красок, грязь,
контраст, замыленность и наклон листа. JavaScript только меняет число и подбрасывает
каждому блоку свой угол дрожи.

## Разработка

Сборка не нужна — достаточно открыть файл или поднять любой статический сервер:

```sh
python3 -m http.server 8000
```

Деплой: пуш в `master`, дальше GitHub Pages сам.

## Пересоздать ассеты

`og-cover.jpg` и `apple-touch-icon.png` собираются из `ava-600.jpg` скриптом `tools/build-assets.py`.
Карточка печатается теми же шрифтами, что и страница, — скачай их с Google Fonts и укажи файлы:

```sh
pip install Pillow
STENCIL_TTF=~/fonts/Oswald.ttf MONO_TTF=~/fonts/PTM55FT.ttf MARKER_TTF=~/fonts/Caveat.ttf \
    python3 tools/build-assets.py
```

Без переменных скрипт возьмёт похожие шрифты из системы — карточка соберётся, но начертания будут другие.
